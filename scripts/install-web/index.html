安装向导

检查服务器、创建网页管理员，然后启动邮件面板。

输入终端上的安装口令

请先核对浏览器证书的 SHA-256 指纹与终端显示的一致。口令只能用一次，15 分钟内有效。

预检与设置

服务器检查

    至少 10 个字符，最多 72 个 UTF-8 字节。这个密码用于登录邮件面板。

    安装后，邮件面板使用局域网 HTTP。仅在可信局域网访问。

    正在安装

    可以刷新或关闭这一页。安装会在服务器上继续，稍后用同一浏览器回来查看。

    进邮件面板请用上一步设置的管理员用户名和密码，不需要再注册。

    独立的 Dovecot 密码 · mailuser

    打开邮件面板 ↗

    安装结束后，向导最多继续开放 5 分钟。
